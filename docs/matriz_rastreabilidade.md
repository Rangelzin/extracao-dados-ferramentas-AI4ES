# Matriz de Rastreabilidade

Este documento vincula os Requisitos Funcionais (RF) e Não Funcionais (RNF) às Histórias de Usuário (US) correspondentes.

## 1. Requisitos Funcionais vs. Histórias de Usuário

| Requisito | Descrição | História de Usuário (US) |
| :--- | :--- | :--- |
| **RF01** | Gestão de Quartos (Cadastro) | **US01**: Cadastrar quartos com amenidades. |
| **RF02** | Lista de Quartos e Status | **US02**: Visualizar lista; **US03**: Alterar status. |
| **RF03** | Gestão de Hóspedes (Cadastro) | **US04**: Cadastrar novos hóspedes com CPF. |
| **RF04** | Lista de Hóspedes | **US05**: Consultar lista de hóspedes. |
| **RF05** | Gestão de Reservas | **US06**: Ver hóspede no quarto; **US07**: Editar reserva. |

## 2. Requisitos Não Funcionais vs. Histórias de Usuário

| Requisito | Descrição | História de Usuário (US) |
| :--- | :--- | :--- |
| **RNF01** | Interface Web | **US08**: Interface moderna e acessível. |
| **RNF02** | Identidade Visual (Verde/Azul) | **US08**: Cores azul e verde em todas as telas. |
| **RNF03** | Componentização (Chips) | **US09**: Uso de Chips coloridos para status. |
| **RNF04** | Arquitetura de Pastas | *Transversal (Aplica-se a todo o desenvolvimento).* |
