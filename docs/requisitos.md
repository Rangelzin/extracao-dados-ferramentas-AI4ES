# Requisitos do Sistema de Reserva de Hotel

## 1. Requisitos Funcionais (RF)

| ID | Descrição |
| :--- | :--- |
| **RF01** | **Gestão de Quartos**: Cadastro de quartos com número, capacidade, tipo, preço e amenidades. |
| **RF02** | **Lista de Quartos**: Visualização de quartos com status de disponibilidade e opção de edição. |
| **RF03** | **Gestão de Hóspedes**: Cadastro de hóspedes com CPF, Nome, Sobrenome e E-mail. |
| **RF04** | **Lista de Hóspedes**: Visualização simplificada de hóspedes cadastrados. |
| **RF05** | **Gestão de Reservas**: Interface para gerenciar a ocupação dos quartos por hóspedes. |

## 2. Requisitos Não Funcionais (RNF)

| ID | Descrição |
| :--- | :--- |
| **RNF01** | **Interface Web**: Aplicação acessível via navegador com design responsivo. |
| **RNF02** | **Identidade Visual**: Paleta de cores baseada em tons de Verde e Azul. |
| **RNF03** | **Componentização**: Uso de componentes modernos (ex: Chips para status, selects estilizados). |
| **RNF04** | **Arquitetura**: Separação clara entre código (`code/`) e documentação (`docs/`). |
